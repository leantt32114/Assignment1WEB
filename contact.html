Architecture Comparison: RDNA 3 vs RDNA 4

Comparison of key architectural features between RDNA 3 and RDNA 4
Feature RDNA 3 RDNA 4 Improvement
Process & Design TSMC 5nm + 6nm (chiplet) TSMC 4nm (monolithic) Simpler, more efficient design
Ray Tracing 2nd generation, Optimized Ray Accelerators 3rd generation, doubled ray intersection rates Up to 2x faster ray intersection
AI Acceleration (Matrix) 1st generation, Wave Matrix Multiply Accumulate 3rd gen Matrix Acceleration with ML-based upscaling Dedicated AI pipelines for FSR 4
Cache System Up to 96 MB Infinity Cache 64 MB 3rd gen Infinity Cache + 8 MB L2 More balanced cache hierarchy
Memory Interface Up to 384-bit GDDR6, 20 Gbps 256-bit GDDR6, up to 20 Gbps Offset by larger cache
PCIe Interface PCIe 4.0 PCIe 5.0 2x more bandwidth
Source Data taken from official AMD presentation materials
